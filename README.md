##  Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/ArthKathiriya08/React-Js-Project-3.git
```

**2. Open the project folder**

```bash
cd React-Js-Project-3
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```
